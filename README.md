# muhammadhassan.eu

Personal portfolio of Muhammad Hassan (GitHub Pages).

- `index.html` – the website
- `reader.html` – online book reader (reads `files/books/<book>.txt` first, then the PDF)
- `share/` – small preview pages used when a book link is shared (Open Graph image + title)
- `js/` – scripts (`pdfjs/` is the PDF engine, hosted on this site)
- `css/`, `img/`, `lib/`, `files/` – styles, images, libraries, PDFs
